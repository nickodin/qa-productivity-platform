# Learning Plan

## Goal

Within 6 months, become competitive for higher-paid technical QA roles and create a realistic path to total monthly revenue of 40,000+ PLN through:

- a higher-paid primary contract;
- an additional part-time contract;
- or a combination of both.

## Target Roles

- Senior Quality Engineer
- SDET
- QA Automation Engineer
- QA Productivity Engineer
- Internal Tools Engineer
- AI Workflow Automation Engineer

## Current Starting Point

- Manual QA
- Production support
- Mobile applications
- BigQuery and SQL
- Log investigation
- AI tools used inside the company
- English: B1
- Polish: A2
- Limited understanding of programming code

## Learning Format

- Small tasks lasting 30–90 minutes
- Reading and reviewing code before writing code
- Synthetic examples only; no confidential company code
- AI may generate code, but every important part must be understood
- Each completed topic is recorded in this repository

## Six-Month Roadmap

### Month 1 — Reading Python and Git Basics

- Understand basic Python syntax
- Read small scripts
- Understand functions, variables, conditions and loops
- Understand file processing
- Learn basic Git and GitHub workflow

### Month 2 — Python Tools and Testing

- Work with files, JSON and regular expressions
- Understand modules and project structure
- Understand errors and logging
- Read and modify simple pytest tests
- Review AI-generated Python code

### Month 3 — API and Backend Fundamentals

- HTTP and REST
- Requests and responses
- JSON APIs
- Authentication basics
- SQL practice
- Build and understand a small API client

### Month 4 — AI Engineering Fundamentals

- LLM APIs
- Structured outputs
- Tool calling
- Context management
- MCP fundamentals
- AI output evaluation
- Security and prompt injection basics

### Month 5 — Production-Quality Internal Tool

- Combine Python, API, SQL and AI
- Add tests
- Add error handling
- Add logging
- Add configuration and secrets
- Add Docker basics
- Document technical decisions

### Month 6 — Market Preparation

- Finish one public portfolio project
- Prepare technical CV and LinkedIn
- Practice explaining technical decisions in English
- Review real vacancies
- Begin applications and part-time contract search
- Practice technical interviews
