# QA Productivity Platform

## Overview

QA Productivity Platform is an engineering project focused on building AI-powered tools that improve the daily work of QA Engineers.

The goal is not to replace testers, but to automate repetitive investigation tasks, improve debugging workflows, and increase engineering productivity.

---

## Long-term Goal

Build a production-quality platform that includes tools such as:

- Android Log Investigation
- iOS Log Investigation
- AI Investigation Assistant
- BigQuery Assistant
- Jira Assistant
- Report Generator

---

## Learning Journey

This repository is also used as a learning workspace.

Every feature is built while studying software engineering, backend development, AI engineering and system design.

The focus is on understanding engineering decisions instead of simply generating code with AI.
